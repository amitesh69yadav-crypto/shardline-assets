# shardline-assets

Web-optimised character, map and weapon models streamed by the SHARDLINE browser FPS. Each model is a
third-party work licensed under **Creative Commons Attribution 4.0** (CC BY 4.0); this
repository redistributes modified copies under the same license, with credit below.

**Modifications made for web streaming (robots):** textures downscaled (base colour to
2048 px, other maps to 1024 px) and re-encoded as JPEG/PNG; normal and occlusion maps
removed; legacy specular-glossiness materials converted to metallic-roughness. Geometry,
rigs and UVs are unchanged.

**Modifications made for web streaming (maps and weapons):** meshes merged per material, textures downscaled (1024 px; large map atlases 2048 px; metal/roughness 512 px) and re-encoded as JPEG/PNG, specular extension removed, vertex colours stored as 8-bit. Weapons: loose display parts lying beside the gun (pistol flashlight and bayonet, rifle scope and foregrip) removed. Desert City: a duplicated copy of the town and leftover editor objects (sky dome, checker planes, UI cards) removed. Geometry and UVs are otherwise unchanged.
